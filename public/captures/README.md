# Captures et vidéos du deck

Déposer ici les fichiers **au nom indiqué** : la slide les affiche automatiquement
(composant `components/Capture.vue`). Tant qu'un fichier manque, la slide montre un
cadre « Capture à venir », visible en répétition.

Formats : `.png` pour une capture, `.mp4` ou `.webm` pour une vidéo (lue sans son,
lancée au clic). Largeur conseillée : 1600 px. Pas de nom de système ou d'utilisateur
professionnel à l'écran.
